# Путеводитель российской семьи — концепт-прототип, версия 2

Прототип раздела «Жизненные ситуации» в стиле портала Госуслуг. Проект «Уверенность в будущем», программа «Код лидера».

**Не является официальным сервисом.** Тексты — черновик, проверяются экспертами.

Предыдущая версия (бэкап): https://ekaterinaeap.github.io/family-navigator/

- `index.html`, `styles.css`, `app.js` — статический сайт без сборки.
- `data.js` — каталог (10 сфер, 36 ситуаций), 4 пошаговых плана, истории героев и **скрипт Проводника** (`guide`): чтобы заменить сценарий бота, правьте тексты и варианты ответов в этом блоке.
- QR-вход из книги: `#/s/<slug>`, коды для печати — `#/qr`. Истории — `#/istorii`.
