# Путеводитель российской семьи — онлайн-навигатор (концепт-прототип, v3)

Прототип раздела «Жизненные ситуации» в стиле портала Госуслуг. Проект «Уверенность в будущем», программа «Код лидера», Группа АБР.
**Не является официальным сервисом и не связан с порталом Госуслуг.** Материалы проходят экспертную проверку; ссылки и телефоны сверены с официальными сайтами 20.10.2026.

## Что есть
- Главная: поиск своими словами, голосовой ввод, 10 сфер и 36 ситуаций, 4 маршрута, инструменты, примеры из жизни, книга и QR.
- 4 маршрута с независимыми шагами (начать можно с любого): уход за близким (I0–I8), смена профессии (A1–A7), ребёнок растёт (M0–M9), планирование ребёнка (P1–P6).
- У каждого шага: что сделать, что подготовить, куда обратиться, чек-лист, меры поддержки, статус, сохранение в план, прямая ссылка.
- Опросник «Подобрать помощь по уходу» (#/care-check), «Мой план», меры поддержки, консультации, сообщества, помощник (текст и голос).
- Без изображений: только типографика и функциональные QR-коды.

## Работает сейчас / требует интеграции / требует проверки
- **Работает:** маршруты, поиск, чек-листы, статусы, план (localStorage), опросник, помощник по правилам, озвучивание, голосовой ввод (Chrome, Edge, Safari), QR.
- **Требует интеграции:** запись к врачу и подача заявлений (сейчас — переход на официальный сайт), действующие сообщества, запись к специалистам.
- **Требует экспертной и региональной проверки:** все меры поддержки, условия и региональные контакты.

Данные — `data.js` (каталог, маршруты, меры, истории, тексты помощника). Предыдущие версии: https://ekaterinaeap.github.io/family-navigator/ (v1).
